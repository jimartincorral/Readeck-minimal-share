First release of **Readeck Share**, a tiny Android app that adds Readeck to the system share menu. Share a link from any app and it's saved to your [Readeck](https://readeck.org) server — without leaving the app you're in.

## Features

- **No taps needed.** Pick "Readeck" in the share menu and the link is saved right away. A small sheet at the bottom of the screen shows *Saving… → Saved ✓* and closes itself.
- **Works offline.** Links shared while offline, or while the server can't be reached, are queued and sent automatically once you're back online.
- **See what's waiting.** Unsent links are listed at the top of the app with their status (waiting, retrying, or failed and why). Retry or remove each one, or tap it to open it in your browser.
- **Default labels.** Optionally add the same labels to every link you share.
- **Small and private.** No tracking or analytics; the app only talks to your own server. Your API token stays on the device and is excluded from backups.

## Install

1. Download `readeck-share-v1.0.0.apk` below and open it on your phone (allow installing apps from your browser or file manager if asked).
2. In Readeck, go to **Settings → API tokens** and create a token that can add bookmarks.
3. Open **Readeck Share**, enter your server URL and the token, and tap **Save and test connection**.

Requires Android 8.0 or newer.

> If you installed a test build from GitHub Actions earlier, uninstall it first: release builds are signed with a different key.
